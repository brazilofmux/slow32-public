# SLOW-32 Runtime Library Map

## Core Assembly Files (Hand-written, must stay as .s)

- `crt0.s` - Startup code, provides _start entry point
- `divsi3.s` - Hand-optimized division routines (__udivsi3, __divsi3)
- `intrinsics.s` - LLVM intrinsics (memcpy, memset, lifetime markers)
- `intrinsics_extra.s` - Additional runtime support (memcpy alias, strlen)
- `stdlib.s` - putint function for integer output
- `setjmp.s` - setjmp/longjmp
- `unwind_asm.s` - entry glue for `_Unwind_RaiseException`/`_Unwind_Resume`
- `builtins_hk.s` - not hand-written: hook thunks for the 64-bit builtins, generated by the Makefile from `builtins.c`

## C Source Files (Compiled to .s then .s32o)

A selection; the authoritative list of what goes into each archive is the
`*_OBJS` variables in `runtime/Makefile` (`COMPILER_RT_OBJS`,
`LIBC_CORE_OBJS`, `STDIO_DEBUG_OBJS`, `STDIO_MMIO_OBJS`,
`LIBC_MMIO_EXTRA_OBJS`, `LIBC_DEBUG_EXTRA_OBJS`, `CXXRT_OBJS`).


- `builtins.c` - 64-bit arithmetic builtins (__udivdi3, __divdi3, etc.)
- `convert_extra.c` - String conversion functions (itoa, utoa, ltoa, ultoa)
- `ctype.c` - Character classification (isalpha, isdigit, etc.)
- `debug_char.c` - DEBUG instruction wrapper (inline assembly)
- `flush_debug.c` - Flush function for DEBUG I/O backend
- `flush_mmio.c` - Flush function for MMIO I/O backend
- `malloc.c` - Memory allocation (malloc, free, calloc, realloc)
- `memory_extra.c` - Additional memory functions (memrchr)
- `printf_enhanced.c` - Printf family implementation (the one built; `printf.c` is an older copy not in the Makefile)
- `putchar.c` - Character output via DEBUG instruction (inline assembly)
- `stdio.c` - Standard I/O functions (fopen, fclose, etc.)
- `stdio_buffered.c` - Buffered I/O implementation
- `stdio_minimal.c` - Minimal stdio (puts function)
- `stdlib_extra.c` - Additional stdlib functions (qsort, bsearch, strtol)
- `stdlib_utils.c` - Utility functions (exit, abort, rand, srand)
- `string.c` - Basic string functions (strcpy, strcmp, strlen, etc.)
- `string_extra.c` - Additional string functions (strdup, strtok, etc.)
- `yield.c` - YIELD and HALT instructions (inline assembly)

## Archives Built

- `libs32.s32a` - Compiler runtime (intrinsics, division, builtins, libm)
  - Contains: `COMPILER_RT_OBJS` -- intrinsics, intrinsics_extra, math_hw,
    math_soft, math_fma, math_cordic, builtins, builtins_hk, divsi3,
    debug_char

- `libc_debug.s32a` - C library using DEBUG instruction for I/O
  - Contains: `LIBC_CORE_OBJS` + putchar.s32o + stdio_minimal.s32o + the
    `*_stub` fallbacks (`LIBC_DEBUG_EXTRA_OBJS`)

- `libc_mmio.s32a` - C library using MMIO for buffered I/O  
  - Contains: `LIBC_CORE_OBJS` + `STDIO_MMIO_OBJS` (stdio, stdio_buffered,
    flush_mmio, memstream, sscanf) + the MMIO services
    (`LIBC_MMIO_EXTRA_OBJS`: files, terminal, network, exec, tube, DPC,
    scheduler, poll, crypto, ...)

- `libs32cxx.s32a` - The C++ run time for freestanding C++ (`CXXRT_OBJS`:
  guards, new/delete, exceptions, RTTI, the std:: exception classes);
  linked after libc.  A program on libc++ links libc++abi in its place.

## Link Order
```
crt0.s32o user.s32o libc_debug.s32a libs32.s32a
```
or
```
crt0.s32o user.s32o libc_mmio.s32a libs32.s32a
```

## Locales

libc has the C locale ("C", "POSIX", "C.UTF-8") and refuses every other
name.  The named locales -- the 53 CLDR 46 locales libutf has collators
for, with their dates, numbers, currency and collation -- are
`locales.s32o`, an object linked ahead of libc by a program that wants
them; its collation tables want `--rodata-size 2M`:
```
crt0.s32o user.s32o locales.s32o libc_mmio.s32a libs32.s32a
```
A program that does not link it does not carry it: libc reaches it only
through weak references.  `locale.c`'s header says what each category
changes and how names resolve; `gen_locales.py` makes `locales_data.h`.
