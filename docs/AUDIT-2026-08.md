Cross-slice review of the central repo (`~/slow-32`) after satellite
tours of `~/llvm-project`, `~/qemu`, and `~/fpc`. Goal: separate **live**
bugs and opportunities from **stale** per-directory `ISSUES.md` notes,
and leave a durable map for fix prioritization.

| Field | Value |
|-------|--------|
| Date | 2026-08-08 |
| Scope | Runtime, host toolchain, emulators/DBT, LLVM/QEMU/FPC backends, selfhost, apps |
| Out of scope | Landing fixes (this doc is findings only) |
| Related | Per-tool `ISSUES.md`, `docs/IMPROVEMENTS.md`, `selfhost/ISSUES.md` |

**How to use this document**

- Prefer this file over older `ISSUES.md` entries when they conflict;
  many trackers are historical review logs with resolved items still open.
- Cross-links point at paths and existing trackers; re-verify before coding.
- Docker pins and Alpine bases were aligned during the audit window
  (see §0). FPC satellite work landed in commit `5564884e` and may continue
  to bump `FPC_COMMIT` / `fpc-backend/**` independently.

## 2. Slice 1 — Runtime (`runtime/`)

### 2.1 Strengths

- `crt0.s` zeros BSS via `memset` (DBT/QEMU intercept-friendly).
- `setjmp`/`longjmp`: full callee-save set + SP/FP/LR; longjmp forces nonzero.
- Segregated free-list `malloc`, overflow-safe `calloc`.
- Single-hart atomics honestly modeled as plain loads/stores.
- Guest `READ_DIRECT` autodetection already in `stdio.c`.
- Real `ungetc` in `stdio.c` (not a no-op).

### 2.2 Open issues (runtime `ISSUES.md` + recheck)

| ID | Item | Severity | Notes |
|----|------|----------|--------|
| R4 | Trig range reduction for large \|x\| | Correctness/math | Payne–Hanek still recommended |
| R8 | Security-engine MMIO (AES/SHA/Ed25519) | Opportunity | Opcode range 0x50–0x5F sketched in ISSUES |
| R9 | High-res timer / `clock()` | Opportunity | `clock_gettime` exists on MMIO path; `clock()` still stub 0 |
| R10 | `READ_DIRECT` host coverage | Cross-slice | Guest ready; verify every emulator |

### 2.3 Live findings

1. **Coarse `errno` mapping** — `mmio_request.c` maps only `EINTR` and
   `ERR→EIO`. Layout header still says “errno wiring TBD.” Apps that
   branch on `ENOENT`/`EINVAL` get wrong diagnostics.
2. **`free()` has no double-free / invalid-pointer guard** — freelist
   corruption on double free; OK for trusted guests, bad for buggy apps.
3. **`rewinddir` is fake** (`dirent_mmio.c`) — resets `dd_loc` only;
   does not re-seek the host directory. Documented TODO, real correctness
   hole for anything that rewinds.
4. **DEBUG vs MMIO libc split** — intentional; easy to mis-test
   (works under MMIO, fails under DEBUG stubs).

### 2.4 Opportunities

- Richer MMIO status → errno table.
- `REWINDDIR` opcode or store path in `DIR`.
- Meaningful `clock()` or document “use `clock_gettime` only.”
- Drop dead `printf.c` if unused (archives use `printf_enhanced`).

## 3. Slice 2 — Host toolchain

Sources: `slow32asm.c` (~3.4k), `s32-ld.c` (~2.6k), `s32-ar` / `slow32dis` /
`slow32dump` (~2k).

### 3.1 Tracker hygiene (stale → fixed)

| Claimed issue | Reality |
|---------------|---------|
| Linker archive buffer leaks on success | Fixed (success + fail free) |
| Linker O(N²) symbol/string lookups | Mostly fixed (`s32_hashmap`) |
| Fixed global tables / stack strtab | Fixed (`DARR_PUSH`, heap) |
| `get_reg_name` 8-byte overflow | Fixed (16-byte + `snprintf`) |
| dump/dis section bounds | Mostly fixed (64-bit extents, forced NULs) |
| ar missing delete | Fixed (`d`/`m`/`x`/`p` present) |

### 3.2 Live findings

1. **Archive resolution still O(n⁴)** — `is_symbol_undefined()` nested-scans
   all input-file symbols for every archive symbol per fixed-point pass.
   Hash maps exist for the *final* symbol table but are not used during
   archive pulls. Fine for today’s small `libc_*.s32a`; will hurt fat
   archives / C++.
   **Fix:** maintain a live undefined-set or partial `symbol_map` as
   objects load.
2. **Error-path leaks in `load_object_from_memory`** — allocations on
   failure path not always freed; link aborts soon after (hygiene).
3. **Assembler token table is 8 MB static BSS** —
   `tokens[MAX_TOKENS][MAX_TOKEN_LEN]` with `MAX_TOKEN_LEN=16384`. Safe
   (not stack), not re-entrant, wasteful. Token overflow *is* checked.
4. **Thin reloc error context** — PC reported; symbol/section/file not
   always included for every reloc flavor.
5. **No negative/malformed object regression suite** — hardened loaders
   exist; almost no tests feed corrupt headers (also in
   `docs/IMPROVEMENTS.md`).

### 3.3 Strengths

- HI20/LO12 sign-bit adjustment, PCREL pairing, hard fail on unresolved/range.
- Section alignment honored in merge/layout; weak vs strong multi-def.
- Assembler: CFI, label-diff, `%hi` rejection on imm12, branch aliases.

## 4. Slice 3 — Emulators + DBT

| Binary | Role |
|--------|------|
| `slow32` | Reference interpreter (strict alignment, f64 reg checks on) |
| `slow32-fast` | Optimized interpreter (strict off unless `S32_STRICT_ALIGNMENT`) |
| `slow32-dbt` | Production Stage-4 DBT (`tools/dbt`) |
| `slow32-dbt5` | Experimental Stage-5 IR/RA — **not** production |
| `qemu-system-slow32` | TCG (see §5.2) |

### 4.1 Open correctness (`docs/IMPROVEMENTS.md` + regression)

| ID | Issue | Evidence |
|----|--------|----------|
| E1 | DBT intrinsic OOB reports **wrong fault address** | `bug-dbt-intrinsic-bounds*` |
| E2 | QEMU exits **silently** / weak diagnostics on same OOB | same differential |
| E3 | QEMU guest exit codes | **Re-check:** `helper.c` now exits with `regs[1]`; IMPROVEMENTS may be stale |
| E4 | x64 DBT superblock back-edge needs Linux build+test | IMPROVEMENTS note |

Self-loop / reg-pressure corruption (DBT ISSUES #11): **investigated;
does not reproduce** on current A64/x64 paths; coverage under
`bug-dbt-backedge-regpressure/`.

### 4.2 Architecture risks

- Host OOM / MMIO thrash (open-fd / path-length caps missing).
- Dual code buffers in DBT (Stage-1 64 KB path vs 4 MB block cache) —
  ISSUES partially outdated if production always uses the block cache.
- `yield_spin_count` false positives (3 yields with no ring progress).
- Alignment: reference traps, fast does not by default (masks toolchain bugs).
- Global `mmio_state` in DBT (no multi-instance).
- Fixed 256 MB guest memory (not CLI-configurable like linker layout).
- **dbt5:** large ISSUES list mostly DONE; still experimental, shadow
  fallback default, not in production differential matrix.

### 4.3 Opportunities

- Fix intrinsic fault-address reporting (closes differential noise).
- QEMU fault messaging + confirm exit-code propagation in CI.
- Shared intrinsic table across dbt / qemu / intercepts.
- Portable profiling (`rdtsc` → `clock_gettime`).

## 5. Slice 4 — Language backends

### 5.1 LLVM (`llvm-backend/`)

**Status is strong** (`SLOW32/STATUS.md`, 2026-08-08): atomics→plain loads,
emutls, f32/f64 with `+f`, long-branch PostRA only (r2 reserved), varargs
f64 straddle, blockaddress, jump tables, CFI. Lit suite: 38 tests, mirrored
in `~/llvm-project`.

Historical docs (`docs/LLVM_BACKEND_ISSUES.md`, varargs/blockaddress
writeups) are **FIXED archaeology**.

| Soft spot | Notes |
|-----------|--------|
| Orphan `llvm-backend-improvements-sep16-18.patch` | Not applied by Docker 01–05; fails dry-apply on current pin — delete or archive |
| f64 inline-asm pairs | Unsupported |
| `-mattr=-f` soft-float completeness | RTLIB map present; smoke-test vs compiler-rt |
| Schedule model | `SLOW32Schedule.td` not tuned to real RTL |
| pitstop O1/`stmt_free` | Suspected miscompile; fixed in-tree via **sbasic AST cleanup** (no `optnone` today). If it returns, reduce IR and file as backend bug |

### 5.2 QEMU (`qemu-backend/`)

- **ISA decode complete:** 92 opcodes match `tools/emulator/slow32.h` with
  zero name/value mismatches.
- Unknown opcode → halt + shutdown (not infinite park).
- `READ_DIRECT` present; MMIO service set largely mirrors host emulators.
- Guest exit via `regs[1]` in `helper.c` (verify CI still treats exit as
  “output only” if IMPROVEMENTS is stale).
- Open: fault UX vs reference; automate full regression through
  `scripts-qemu/slow32/functional.py`; optional Avocado/`tests/tcg/slow32`.
- Interrupts not implemented (by design, single-hart).

### 5.3 FPC (`fpc-backend/`)

Satellite work completed in-tree (`5564884e` and prior syncs). Upstream
pin `fa4cff4b93`; SLOW32 commits on `~/fpc` sit on top (~15 commits).

**Strengths**

- Full pipeline: Pascal → `ppcs32` → `slow32asm` → `s32-ld` → emu.
- Native **f32** under `-CfSLOW32` (F-class aliases r20–r28).
- Native **f64** under `-CfSLOW32` via even-pair scratch + `F*.D`
  (README status section is **stale** — still claims softfloat-only f64).
- Soft-float default; dual RTL: `runtime/` vs `runtime/fpu/`.
- u32 div/mod via `fpc_div_dword` / `fpc_mod_dword`.
- ANDI/ORI/XORI uimm12 discipline; setjmp returns in r1.
- Review gate: 37-check regtest + 18-check fputest (claimed both modes).

**Gaps / risks**

| Item | Notes |
|------|--------|
| README / `cpubase` TODOs stale | Claim pair codegen TODO while `A_FADD_D` path is live |
| Docker RTL subset | Skips `ISO7185UNIT` (EAccessViolation), `SYSCONSTUNIT`
  (needs `TResourceStringRecord`), blanks `CPU_SPECIFIC_COMMON_UNITS` |
| Huge checked-in RTL artifacts | ~7+ MB `.s`/`.ppu`/`.s32o`; easy to desync |
| `runtime/fpu/` lacks prebuilt `.s32o` | Soft path has it; FPU reassemblies from `.s` |
| No `fpc-backend/ISSUES.md` | Unlike other major slices |
| Mixed single/double | Falls back to softfloat helpers (correct, footgun) |

**Opportunities:** Fix ISO7185 ICE; sysconst → unlock sysutils chain;
document f64 pair ABI; in-repo test harness for the 37+18 checks.

## 6. Slice 5 — Selfhost (Thompson trust root)

**Covered in this audit.** Canonical philosophy:
`selfhost/docs/BOOTSTRAP.md`.

### 6.1 Model

1. **Trust is auditable** — only opaque binary is Stage 0 emulator
   (~780 lines of host C). Everything above is inspectable source.
2. **A stage is one agreement** (format contract among as/ar/ld/cc),
   not one artifact.
3. **Every cycle ends with a gate** — fixed-point, purity, conformance,
   or checksum.

| Stage cluster | Role |
|---------------|------|
| 00 | Minimal host emulator |
| 01 | Forth as/ar/ld/cc + kernel fixed-point |
| 02 | Forth → C (retire Forth tools) |
| 03–04 | Self-sufficient C |
| 05–06 | HIR/SSA / quality |
| 07–08 | Capability (DBT, emulator *inside* SLOW-32) |
| 08-cross-{x64,a64} | Host-native cross compilers (GCC-parity story) |

Primary tracker: `selfhost/ISSUES.md` (Sections A–E). **Section A** is
closed history. **Section B** still contains many FIXED writeups mixed
with live items — use tags carefully.

### 6.2 Active / real gaps (Section B + C + E)

| ID | Tag | Summary |
|----|-----|---------|
| #7 | INCONSISTENCY | JAL is PC-relative; branches are PC+4 — assembler compensates; design footgun |
| #12 | NARROWED | Stage02 `s32-ar` still short of full `d/m/v/p` parity |
| #46 | LIMITATION | 12-bit frame scaffolding; 256 KB user stack; spill × recursion fragility |
| #35 | LIMITATION | Preprocessor gaps (Section C) |
| #38 / #47 | MISSING | Third-party C dialect / some by-value edges |
| #49 | DEFERRED | Full float printf formats in *selfhost* libc |
| #54–#56 | OPEN | **Legacy `cc.fth`**: unreachable `P-MINUS`; multi-level array hang — only if Forth-stage compiler still used |

### 6.3 Opportunities (Section D)

- Memory-SSA / GVN.
- Tail-call optimization.
- Keep `verify-emu-sums` / fixed-point gates sacred.

### 6.4 Risk pattern

Any regalloc/spill regression + recursive parser (s12cc) can look like a
“hang” that is actually **stack overflow**. Prefer `slow32-fast` over DBT
when chasing recursion-depth issues (`slow32-dbt` has historically masked
stack faults).

4. **Runtime** richer errno mapping.

### Scale / bootstrap

8. **Selfhost #46** awareness: stack size / spill for third-party C.

11. Delete or archive orphan LLVM `llvm-backend-improvements-sep16-18.patch`.
12. Refresh stale trackers: tool `ISSUES.md`, `docs/IMPROVEMENTS.md` (QEMU

## 9. What *not* to re-litigate

These were open in old trackers but are **done** or **design**:

- LLVM: varargs ORI bug, blockaddress, UDIV libcalls, inline asm scaffold.
- Linker: dynamic tables, hash maps (except archive *undef* path), PCREL_LO12.
- Assembler: dynamic symbols/relocs, branch range `exit(1)`.
- QEMU: READ_DIRECT missing (fixed).
- DBT self-loop shuffle corruption (does not reproduce on current paths).
- dBase bulk of Feb-2026 correctness items (resolved).
- Host endianness of Stage0 (NOT SUPPORTED — LE only).
- Single-hart / no interrupts (intentional architecture).
